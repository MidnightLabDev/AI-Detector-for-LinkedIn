AI Detector for LinkedIn® 0.1

This build uses Zhuque AI only.

Detector

Zhuque AI through Tencent EdgeOne Makers
Endpoint: https://ai-gateway.edgeone.link/v1/providers/zhuque-text/classify
Output: Human, AI and Suspected AI

English only

The extension sends text to Zhuque only when Chrome reliably identifies it as English.
Unconfirmed or non-English text is skipped.

Bring your own API key

Users provide their own Tencent EdgeOne API key.
Session storage is used by default.
Remember on this device stores the key in the browser profile local storage.

Detection

The extension analyzes eligible LinkedIn posts, comments and replies.
It shows only the highest scoring result beside each analyzed item.

Minimum words

Users can choose the minimum number of words required before a request is sent.

RAID Benchmark

The popup keeps a link to:
https://raid-bench.xyz/leaderboard

No leaderboard position is claimed or guaranteed by this build.

Troubleshooting

If the extension shows Analysis failed after the first run, refresh the LinkedIn page and try again.
