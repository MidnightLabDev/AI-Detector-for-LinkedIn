AI Detector for LinkedIn®

An independent browser extension by Mayas Ötegen. You provide your own Zhuque AI API key.

Detector

This release uses Zhuque AI through Tencent EdgeOne. Eligible LinkedIn® text is sent only to the Zhuque AI endpoint configured by the extension.

Text sent for detection

When detection is enabled, the extension extracts eligible visible post and comment body text from supported LinkedIn® pages and sends that text to Zhuque AI for inference. The minimum word setting is applied before a request is made. The extension is designed to send the post or comment body, not profile headers, images, profile URLs, private messages, connections or account details. Personal information written inside a post or comment can still be included in the text sent to Zhuque AI.

Your API key

Session storage is the default. If you choose Remember on this device, your Zhuque AI key is saved in the local storage of this browser profile. Chrome local storage is not an encrypted password vault. The API key is not sent to LinkedIn®, returned to the content script, placed in Chrome sync or sent to an additional AI detector. Remove key clears the stored Zhuque AI key.

Local extension data

Preferences and the Zhuque connection record are stored locally. Up to 1,000 text hashes and model results, request counters, and up to 1,000 timing samples can remain in extension session storage. Raw page text is kept in working memory while a request is being handled. This extension does not operate a separate analytics or inference server.

Check this page reads local detection counts and reason codes from the active LinkedIn® tab. It does not itself send an inference request and does not return an API key, post body text, comment body text, author details or page URL to the popup.

Zhuque AI results

Zhuque returns three proportions: Human, AI and Suspected AI. The extension keeps all three categories separate and displays the category with the highest returned proportion.

In this extension, Zhuque detection is restricted to text that Chrome reliably identifies as English. Text that cannot be reliably confirmed as English is skipped and is not sent to Zhuque.

Provider data handling

Text sent to Zhuque AI is subject to Tencent EdgeOne's current service terms and privacy practices. Review the current Tencent documentation before using the extension with sensitive content.

RAID Benchmark

The popup includes a link to the public RAID leaderboard as an external benchmark reference. The extension does not state or guarantee a particular leaderboard position. Rankings and model versions can change over time, and benchmark performance does not guarantee the same result on LinkedIn® posts, comments or every writing style.

General limitations

AI text detection is probabilistic. Results can be wrong, especially for short text, translated material, heavily edited text, mixed human and AI writing, unusual formatting or content outside the supported language. A result should not be treated as proof that a particular person did or did not write a piece of text. LinkedIn® page layouts can also change. Images and videos are not analyzed.
