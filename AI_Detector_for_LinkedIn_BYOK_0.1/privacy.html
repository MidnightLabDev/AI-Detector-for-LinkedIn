AI Detector for LinkedIn®

An independent browser extension by Mayas Ötegen. You choose the detector and provide your own API key.

Selected detector

The extension supports Zhuque AI through Tencent EdgeOne and Winston AI through the Winston developer API. Only the detector selected in the popup receives eligible text. Switching providers stops waiting work from the previous provider and uses the key saved for the newly selected provider.

Text sent for detection

When detection is enabled, the extension extracts eligible visible post and comment body text from supported LinkedIn® pages and sends that text to the selected provider for inference. The minimum word setting is applied before a request is made. The extension is designed to send the post or comment body, not profile headers, images, profile URLs, private messages, connections or account details. Personal information written inside a post or comment can still be included in the text sent to the selected provider.

Your API keys

Zhuque and Winston AI keys are stored separately. Session storage is the default. If you choose Remember on this device, that provider key is saved in the local storage of this browser profile. Chrome local storage is not an encrypted password vault. Provider keys are not sent to LinkedIn®, returned to the content script, placed in Chrome sync or sent to another detector. Remove key clears the stored key for the selected provider.

Local extension data

Preferences and provider connection records are stored locally. Up to 1,000 text hashes and model results, request counters, and up to 1,000 timing samples can remain in extension session storage. Raw page text is kept in working memory while a request is being handled. This extension does not operate a separate analytics or inference server.

Check this page reads local detection counts and reason codes from the active LinkedIn® tab. It does not itself send an inference request and does not return an API key, post body text, comment body text, author details or page URL to the popup.

Zhuque AI results

Zhuque returns three proportions: Human, AI and Suspected AI. The extension keeps all three categories separate. Posts show the category with the highest returned proportion. Comments show all three percentages. In this extension Zhuque detection is enabled for English and Arabic.

Winston AI results

Winston AI v2 returns a Human Score from 0 to 100. The extension displays that value as Human and calculates the displayed AI value as 100 minus the Human Score. Winston does not return a separate Suspected AI category through this endpoint, so Winston results show only AI and Human.

According to the Winston v2 API documentation, supported languages are English, French, Spanish, Portuguese, Dutch, German, Polish, Italian, Romanian, Indonesian, Tagalog, Russian, Bulgarian and Simplified Chinese. Arabic is not listed as supported by the Winston v2 text API. Winston requires at least 300 characters for text input and warns that text below 600 characters may produce unreliable results. The extension therefore skips Winston requests below 300 characters even if the minimum word setting is lower.

Provider data handling

Text sent to a provider is subject to that provider's current service terms and privacy practices. Winston states that text submitted through its API is private, encrypted, not shared with other organizations and not used to retrain its model. Review the current provider documentation before using either service with sensitive content.

RAID Benchmark

The popup includes a link to the public RAID leaderboard as an external benchmark reference. The extension does not state or guarantee a particular leaderboard position. Rankings and model versions can change over time, and benchmark performance does not guarantee the same result on LinkedIn® posts, comments, every language or every writing style.

General limitations

AI text detection is probabilistic. Results can be wrong, especially for short text, translated material, heavily edited text, mixed human and AI writing, unusual formatting or content outside a detector's supported languages. A result should not be treated as proof that a particular person did or did not write a piece of text. LinkedIn® page layouts can also change. Images and videos are not analyzed.
